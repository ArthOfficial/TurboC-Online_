Frequently Asked Questions (FAQ)

Everything you need to know about running, compiling, debugging, and troubleshooting C and C++ programs in Turbo C++ Online.

How do I copy and paste code into Turbo C++ Online?
Click the Paste Code button in the top navigation bar or press Shift + Insert (or Ctrl + Shift + V). Paste or write your source code in the dialog, specify your target filename (default: CODE.CPP), and click Insert into Turbo C++. Your code is written directly to the virtual DOS filesystem in TURBOC3/BIN/ and automatically opened in Turbo C++ in 0.3 seconds with 100% exact indentation.
Why does my program close immediately after running, and how do I view output?
After compiling and running with Ctrl + F9, Turbo C++ automatically returns to the code editor once the program finishes. You can view the output screen at any time by pressing Alt + F5 (User Screen). To keep the output window open automatically until a key is pressed, include <conio.h> and add getch(); right before return 0; in your main() function.
Can I compile and run programs using conio.h and graphics.h?
Yes! This emulator runs authentic Borland Turbo C++ 3.2 on DOSBox. Legacy functions like clrscr(), getch(), and gotoxy() from conio.h work perfectly. BGI graphics programs using initgraph() and functions like line(), circle(), and outtextxy() also run properly inside the DOSBox canvas.
How can I import my own C/C++ files from my computer?
You can import files in two ways:
1. Click the Import (.CPP) button in the top bar to choose a file from your hard drive.
2. Drag and drop any .cpp, .c, or .h file directly onto the Launch Card or the Code Insertion modal.
How does Turbo C++ Online differ from installing Turbo C++ on Windows 11 or 10?
Borland Turbo C++ 3.2 is an original 16-bit MS-DOS application that cannot run natively on modern 64-bit editions of Windows 11 or 10. Local installations typically bundle modified, outdated DOSBox wrappers that often trigger antivirus false positives, mount path conflicts, or display scaling issues. Turbo C++ Online runs entirely inside your browser via WebAssembly DOSBox, requiring zero installation, zero admin permissions, and zero software downloads.
Is Turbo C++ Online free, and does it have ads?
Turbo C++ Online is 100% free, non-commercial, and completely ad-free. It does not contain banner advertisements, sponsor redirects, or video popups. It is maintained by Arth for students, programmers, and retro enthusiasts worldwide.
Does this work on Mac, Linux, and Chromebooks?
Yes. Since the emulator runs via WebAssembly directly inside modern web browsers (Chrome, Firefox, Safari, Edge), Turbo C++ Online works seamlessly on macOS, Linux, ChromeOS, and even modern mobile devices.
