Turbo C++ Keyboard Shortcuts & Commands

Master the authentic Borland Turbo C++ 3.2 IDE keyboard navigation. In Turbo C++, nearly every operation can be performed faster with function keys and modifier combinations.

Essential Compiler & Editor Keys

Shortcut Action Details
Shift + Insert / Ctrl + Shift + V Live Code Insertion Opens the external code paste window to inject source code directly into Turbo C++ in 0.3s.
F3 Open File Prompts the File Open dialog to open any .CPP or .C file.
F2 Save File Saves the currently active file buffer to disk.
F5 Zoom / Maximize Window Toggles active editor window between half-screen tile and full-screen workspace.
Ctrl + F9 Compile & Run Compiles, links, and immediately executes your program in the DOSBox environment.
Alt + F5 User Screen Switches to the DOS output window so you can inspect program results. Press any key to return.
Alt + F9 Compile Only Checks syntax and generates .OBJ file without executing.
F9 Make Project Builds the project and links the executable.
Alt + X Exit Turbo C++ Gracefully quits the Turbo C++ IDE.
F11 Toggle Fullscreen Enters or exits immersive Full Big fullscreen mode with crisp pixel scaling.
Esc Dismiss / Exit Fullscreen Closes any open modal/dialog or exits fullscreen mode to return to standard view.

Debugging & Window Management

Shortcut Action Details
F7 Trace Into Executes code line-by-line, stepping into user-defined functions.
F8 Step Over Executes code line-by-line, stepping over function calls without entering them.
Ctrl + F2 Program Reset Terminates the active debugging session and frees memory.
Ctrl + F4 Evaluate / Modify Inspects variable values or calculates expressions during debugging.
F6 Next Window Cycles active focus to the next open editor window.
Alt + F3 Close Window Closes the active editor window.
F5 Zoom Window Maximizes or restores the active editor window size.
