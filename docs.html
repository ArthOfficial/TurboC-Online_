Technical specifications, virtual filesystem mechanics, supported DOS libraries, and compiler guides for Borland Turbo C++ 3.2 in the browser.

Emulation Core & WebAssembly Runtime

Turbo C++ Online runs an authentic Borland Turbo C++ 3.2 installation compiled to run on an x86 real-mode DOS environment. Emulation is executed via JS-DOS 8.4.1 and DOSBox compiled directly to WebAssembly (Wasm).

All execution happens strictly client-side within your browser sandbox. No source code or program data is transmitted to external servers, providing privacy, low latency, and zero dependency on server-side compilers.

x86 Real-Mode Emulation

Runs genuine 16-bit Borland C/C++ compiler toolchain (TCC, TLINK, TASM).

Direct FS Injection

Code is written into the virtual DOS filesystem in 0.3s without typing delays.

VGA/EGA Graphics

Full 320x200 and 640x480 resolution canvas with BGI graphics driver support.

Standard Library Support

Turbo C++ 3.2 comes with standard headers located in INCLUDE/:

• iostream.h / fstream.h: C++ streams (cout, cin, endl).
• conio.h: Console I/O functions including clrscr(), getch(), getche(), wherex(), wherey().
• graphics.h: Borland Graphics Interface (BGI) functions (initgraph(), circle(), line(), closegraph()).
• stdio.h / stdlib.h: Standard C library (printf(), scanf(), malloc(), free()).
• dos.h / bios.h: Low-level DOS and BIOS interrupts (delay(), sound(), nosound()).

Sample Starter Programs
