## Features & Implementation
- **Zero-Setup Execution**: Uses WebAssembly DOSBox to boot DOS and Borland Turbo C++ in under 3 seconds in any web browser.
- **Direct Live Injection**: Rather than simulating slow keypresses over hundreds of lines, external code pasted or imported by the user is written as binary directly into the virtual filesystem (`TURBOC3/BIN/<filename>.CPP`) and loaded via internal F3 shortcut commands in 0.3 seconds.
- **Native File Handling**: Supports uploading and dropping external files directly into the DOS workspace.
- **Ad-Free Commitment**: 100% free of advertising banners, video ads, or trackers.

## Keyboard Reference
- `Shift + Insert` / `Ctrl + Shift + V`: Launch External Code Insertion Dialog
- `F3`: Open File
- `F2`: Save File
- `Ctrl + F9`: Compile & Run
- `Alt + F5`: View Output Screen
- `Alt + X`: Quit IDE
